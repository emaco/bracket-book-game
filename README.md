# The Ultimate Book Boyfriend

A "This or That" book-boyfriend bracket game for a TV screen.

## Run it
Open `index.html` in a browser (or host it — see below).
- **Enter** or **tap/click** to start and advance.
- **← / →** or **tap** to choose a contestant.
- **Enter** again or **tap again** to confirm.

## Controls
Built for a TV remote (arrow keys + Enter) but mouse/touch also work.

## Structure
- `index.html` — the whole game (backgrounds are embedded; photos are external)
- `assets/photos/` — the 12 contestant photos

## Notes
- 12 contestants, round-1 pairs fixed; later rounds re-pair winners at random.
- Odd counts give one contestant a bye.
- The font (Fredoka) loads from Google Fonts, so first load needs internet.
